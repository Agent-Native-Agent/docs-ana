# 출처

이 폴더(`lib/docreview/`)는 사용자가 2026-11-17 Docs 에 넣으라고 준 **doc-review** 패키지(AI Workplace 의 "문서 검토" 기능을 떼어 낸 것, v1.0.0)에서
`lib/rules.js`(규칙 점검 · 종합 판단)와 `lib/ai.js`(AI 검토 지시문 — 여기서는 지시문만 쓴다)를 고치지 않고 가져왔다. 원래 설명은 `README.md`.

- Docs 에서는 문서 읽기(kordoc)·외부 모델 호출(lib/llm.js)·HWPX 보고서는 가져오지 않았다. 글은 Docs 가 이미 읽은 문서의 최종 글을 쓰고,
  AI 검토는 외부 모델 대신 이 ANA 의 에이전트가 `REVIEWER` 지시문대로 읽고 판단한다(문서가 밖으로 나가지 않는다 — skills/doc-review).
- 원 패키지의 규칙 분류와 일부 항목 번호는 epoko77-ai/im-not-ai(MIT License)를 참고해 다시 쓴 것이라고 원 README 가 밝힌다.

## Docs 에서 덧붙인 것

- `owner-rules.js` — 이 Docs 주인이 문서를 고치며 실제로 지적한 것(2026-11-19)을 규칙 7가지로 만든 것: 개조식 끝맺음 누락 · 구호형 키 메시지 · 제품·도구 이름 나열 · 풀이 없는 외래 용어 · 같은 대상을 다른 이름으로 · 요약이 금액 위주 · 체계도에 급이 다른 세부. 원래 `rules.js` 는 고치지 않고, 문서검토를 돌릴 때 함께 돌린다. AI 검토 지시문에도 같은 기준(글자로 셀 수 없는 조판 포함)을 덧붙인다.
