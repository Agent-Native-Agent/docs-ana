# 개념도 — 그린 뒤 확인할 것

`node scripts/snapshot.mjs out/<id>.html`이 만든 PNG 네 장을 연다. PC와 휴대폰을 각각 밝은 화면과 어두운 화면으로 찍은 것이다. 아래 항목을 하나씩 본다.

## 모양

- [ ] 사람 상자의 화살표가 그 사람이 쓰는 단계 상자의 **세로 가운데**에 닿는다.
- [ ] 바깥 시스템 상자가 주고받는 단계와 같은 높이에 있다. 위 화살표는 보내는 것, 아래 화살표는 받는 것이다.
- [ ] 단계 사이 화살표의 촉이 모두 보인다. 촉이 없으면 marker ID가 겹친 것이다. spec `id`를 바꾼다.
- [ ] 글자가 상자 밖으로 나가지 않는다. 스냅샷 출력에 '그림 밖 글자'가 0이어야 한다.
- [ ] 라벨이 선과 겹쳐도 읽힌다(바탕색 테두리).

## 휴대폰(390px)

- [ ] 세로 그림만 보이고 넓은 그림은 숨는다.
- [ ] 화면이 가로로 넘치지 않는다. 스냅샷 출력에 '가로 넘침'이 없어야 한다.
- [ ] 단계 설명 두 줄이 자연스러운 곳에서 끊긴다. 어색하면 spec `modules[].tall`에 직접 쓴다.

## 어두운 화면

- [ ] 상자 테두리, 글자, 화살표가 모두 보인다. 색을 직접 넣은 곳이 없어야 한다(클래스와 토큰만 쓴다).

## 내용

- [ ] 그림의 단계, 역할, 연결이 코드나 문서와 맞는다. 지어낸 것이 없다.
- [ ] 실제 사람 이름, 계정, 키, 주소가 없다.
- [ ] aria-label 한 문장만 읽어도 그림이 무엇을 말하는지 알 수 있다.

## 앱에 넣은 뒤

- [ ] 같은 페이지에 다른 그림이 있으면 marker ID가 서로 다르다.
- [ ] 앱 테마를 바꿔도(밝은 ↔ 어두운) 그림이 따라 바뀐다.
