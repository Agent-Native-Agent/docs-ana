# 순서도·관계도 — 사용자에게 물을 것

먼저 코드·스키마·문서에서 찾을 수 있는 것은 찾아 두고, **모르는 것만** 한 번에 하나씩 짧게 묻는다.

## 먼저 정할 것: 무엇을 그리나

- **순서도**: 일이 어떤 순서로 진행되고, 어디서 갈라지고, 어디로 되돌아가는지
- **관계도**: 무엇과 무엇이 몇 대 몇으로 이어지는지(1:n, n:n)

질문 예: "일이 진행되는 순서를 보이고 싶으신가요, 아니면 항목들이 몇 대 몇으로 이어지는지 보이고 싶으신가요?"

## 순서도라면

1. **시작과 끝**: 무엇이 시작을 알리고, 무엇이 나오면 끝인지 묻는다.
2. **단계**: 순서대로 5~10개를 받는다. 단계마다 2~4개 낱말로 한 일을 적는다.
3. **판단**: 어느 단계 뒤에 '예/아니요'로 갈라지는지, 각 갈래가 어디로 가는지 묻는다.
4. **되돌아감**: 고친 뒤 어느 단계로 돌아가는지 묻는다.
5. **사람이 하는 단계와 시스템이 하는 단계를 나눌지** 묻는다. 나누면 구역(zones)이나 상자 종류로 표시한다.

## 관계도라면

1. **항목(엔터티)**: 이름과 한 줄 뜻, 예시 하나를 받는다.
2. **관계**: A와 B가 몇 대 몇인지, 0개일 수 있는지 묻는다(1 : 0..1, 1 : 0..n).
3. **n : n**: 무엇으로 이어지는지 묻는다. 연결 항목과, 그 연결에만 붙는 값(매개변수 등)이다.
4. **구역**: 미리 등록해 두는 것과 돌릴 때마다 쌓이는 것을 나눌지 묻는다.
5. **세는 법**: 통계가 무엇을 하나로 세는지 묻는다(판정 단위, 문항 단위 등). 표로 붙인다.

## 묻지 말 것

- 색, 좌표, 선 경로. 배치 요령(SKILL.md)대로 정하고, 그린 뒤 보여 주며 확인받는다.
- 코드에 이미 있는 관계(외래 키, 배열 포함 관계). 찾아서 쓴다.
