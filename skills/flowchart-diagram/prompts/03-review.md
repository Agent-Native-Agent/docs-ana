# 순서도·관계도 — 그린 뒤 확인할 것

`node scripts/check.mjs`가 오류 0인지 먼저 확인한다. 그다음 `node scripts/snapshot.mjs out/<id>.html`이 만든 PNG 네 장을 본다.

## 선

- [ ] 모든 선이 상자 변의 가운데에 닿는다(마름모는 꼭짓점).
- [ ] 선이 상자를 뚫고 지나가지 않는다. check의 오류가 0이어야 한다.
- [ ] 화살촉이 모두 보인다. 안 보이면 같은 페이지에 같은 marker ID가 있는 것이니 spec `id`를 바꾼다.
- [ ] 합류점과 분기점에 점이 찍혀 있다. 합류한 선에는 화살촉이 없다.
- [ ] 되돌아가는 선이 다른 상자나 라벨과 겹치지 않는다.

## 글자

- [ ] 상자 글자가 상자 안에 있다. 스냅샷의 '그림 밖 글자'가 0이어야 한다.
- [ ] 관계 수(1, n, 0..1)가 해당 선 끝 옆에 있고 상자와 겹치지 않는다.
- [ ] 라벨이 다른 선이나 점과 겹쳐 읽기 어렵지 않다. 겹치면 labelAt, labelDy로 옮긴다.

## 휴대폰(390px)

- [ ] 페이지가 가로로 넘치지 않는다. 그림 안에서만 옆으로 민다.
- [ ] 옆으로 미는 그림 아래에 '← 옆으로 밀어 전체 보기 →' 안내가 있다.
- [ ] 열이 두세 개인 순서도는 화면 폭에 맞춰 줄어든다(minWidth 0).

## 어두운 화면

- [ ] 구역 바탕, 상자, 선, 관계 수가 모두 보인다. 색을 직접 넣은 곳이 없다.

## 내용

- [ ] 관계 수가 데이터 모델(코드)과 맞는다. 예: 0개일 수 있으면 `0..1`, `0..n`.
- [ ] 표의 관계 행과 그림의 선이 서로 맞는다. 그림에만 있거나 표에만 있는 관계가 없다.
- [ ] 판단 마름모의 갈래가 모두 라벨(예, 아니요)을 가진다.
- [ ] aria-label 한 문장이 그림을 요약한다.
- [ ] 실제 사람 이름, 계정, 키, 주소가 없다.
