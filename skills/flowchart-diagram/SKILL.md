# 이미지 기반 순서도 생성 스킬

AgentTA 홈의 **개념과 관계**를 만든 방식을 묶은 스킬이다.

- 예시 `skills/doc-generate/examples/library-relations.json`(도서 대출 개념과 관계)이 기본 모양이다.
- 예시 `skills/doc-generate/examples/library-loan-flow.json`은 판단에서 갈라지고 되돌아가는 보통 순서도다.

## 그림의 모양

```
┌ 준비 ─────────────────────────────────────────┐
│ [영역] ──1:n──▶ [유형] ──태그──▶ [샘플] ─┐       │
│                                          └─▶ ◇체크 ──n:1──▶ [기준] │
└───────────────────────────────────────────────┘
┌ 실행 ─────────────────────────────────────────┐
│ [실행] ─1:n─▶ [시도] ─1:0..1─▶ [응답] ─1:n─▶ [판정] ◀─●(합류) │
└───────────────────────────────────────────────┘
```

- **격자**: 열 폭 170, 열 간격 230이 기본이다. 행마다 높이를 준다.
  - 상자는 `(col, row)` 칸에 놓는다. 여러 열에 걸치게 하려면 `span`을 준다.
- **상자 종류(kind)**
  - `box`: 보통
  - `core`: 중심(파랑)
  - `map`: 모아 보는 것·분류(주황)
  - `ext`: 바깥(점선)
  - `inner`
  - `terminal`: 시작·끝(둥근)
  - `decision`: 판단·연결(마름모)
- **선(edges)**: `from: "id:변"`, `to: "id:변"`. 변은 top·bottom·left·right 중 하나다.
  - 같은 행이나 같은 열이면 곧은 선이고, 아니면 꺾은 선이다.
  - 꺾은 선의 경로는 `hvh`, `vhv`, `hv`, `vh`가 있고 `route`로 정할 수 있다.
  - `via: "gap:<행>"`, `via: "gapc:<열>"`로 꺾는 위치를 그 틈의 가운데로 옮긴다.
  - `card: ["1","n"]`: 선 양 끝의 관계 수
  - `label`: 선 이름
  - `dashed`: 점선
  - `both`: 양방향
  - `merge: true`: 다른 선에 합류한다. 꺾이는 점에 점을 찍고 멈추며, 화살촉은 합쳐지는 선이 가진다.
  - `dot: "first"`: 갈라지는 점에 점을 찍는다.
- **구역(zones)**: 행 묶음에 옅은 바탕과 제목을 붙인다. 예: '준비 — 등록해 두는 것'.
- **띠(pills)**: 그림 위쪽에 핵심 관계 하나를 강조한다. 예: '샘플 n : n 평가기준'.
- **표(tables)·노트(notes)**: 그림 아래에 관계 설명 표와 예시 문단을 붙인다(`**굵게**` 지원).
- **휴대폰**: 열이 많은 그림은 `minWidth`(기본 760px)를 지키고 옆으로 밀어 본다. 이때 '← 옆으로 밀어 전체 보기 →' 안내가 붙는다.
  - 열이 두세 개인 순서도는 `"minWidth": 0`으로 화면 폭에 맞춘다.

## 순서

1. **사실 모으기**
   - 관계도는 코드의 데이터 모델(테이블·외래 키·배열)에서, 순서도는 실제 처리 코드나 문서의 단계에서 확인한다.
   - 모자란 것은 `prompts/01-interview.md`로 묻는다.
2. **배치 정하기**: 손으로 칸을 먼저 그린다(아래 '배치 요령').
3. **spec 쓰기**: `templates/spec.template.json`을 채운다. LLM에게 맡길 때는 `prompts/02-spec-writer.md`를 준다.
4. **검사**: `node scripts/check.mjs my.json`
   - 오류(상자 겹침, 선이 상자를 뚫음, 없는 상자, 잘못된 변)는 고칠 때까지 다음으로 가지 않는다.
   - 경고(글자 넘침, 라벨이 상자에 걸침, 이어지지 않은 상자)를 확인한다.
5. **그리기**: `node scripts/render.mjs my.json --out out/` → `out/<id>.html`, `out/<id>.svg`
6. **눈으로 보기**: `node scripts/snapshot.mjs out/<id>.html`
   - PNG 네 장(PC·휴대폰 × 밝은·어두운 화면)이 나오고, 가로 넘침과 그림 밖 글자를 함께 검사한다.
   - `prompts/03-review.md`로 확인한다.
7. **넣기**: 둘 중 하나로 한다.
   - `render.mjs`를 import해 `figureHtml(spec)`(+ `tableHtml`)을 넣는다.
   - SVG를 붙이고 `templates/theme.css`의 `.dg*` 규칙을 앱 CSS로 옮긴다.

## 배치 요령

- **흐름 방향을 하나로**: 관계도는 왼쪽에서 오른쪽(실행 사슬), 위에서 아래(준비 → 실행)로 둔다. 순서도는 위에서 아래로 두고 예외 처리만 오른쪽 열로 뺀다.
- **곧은 선이 되게 칸을 고른다**: 직접 이어지는 두 상자는 같은 행이나 같은 열에 둔다. 꺾은 선은 빈 칸과 틈으로만 지나가게 한다(check가 뚫는 선을 잡는다).
- **한 변에 선 둘이 들어오면 합류**: 둘째 선은 `merge: true`로 첫째 선에 합류시키고 점을 찍는다(예: 채점 모델 → 기준→판정 선). 한 변에서 둘로 나가면 `vhv` + `dot: "first"`로 가른다(예: 판정 → 두 통계).
- **n : n은 가운데 연결 상자로**: 두 쪽 사이에 마름모(`decision`)를 두고 `1 : n`, `n : 1`로 푼다. 위쪽 띠(pills)로 'A n : n B'를 따로 적는다.
- **라벨 자리**
  - 기본 자리는 이렇다: 가로선은 가운데 위, 세로선은 오른쪽, 꺾은 선은 가운데 토막.
  - 세로선이 다른 선과 만나는 행을 지나가면 `labelAt: "gap:<행>"`으로 행 사이 틈에 놓는다.
  - 조금만 옮기려면 `labelDx`·`labelDy`를 쓴다.

## 지킬 것(AgentTA에서 겪고 정한 것)

- **좌표는 격자 상수에서만** 낸다. 상자 크기를 바꾸려면 `grid`·`rows`를 바꾸고, 낱개 좌표를 박지 않는다.
- 선은 **상자 변의 가운데**에 닿는다(마름모는 꼭짓점).
- **그림마다 marker ID를 다르게** 한다(spec `id`). 같은 페이지에 그림이 둘이면 id를 달리한다.
- **색은 클래스와 토큰으로만** 준다. 관계 수와 라벨은 바탕색 테두리를 둘러 선 위에서도 읽힌다.
- **aria-label**: spec `aria`에 그림 전체를 한 문장으로 쓴다. 비우면 선 목록으로 자동으로 만든다.
- **말**: 상자 제목은 2~8자로 쓰고 설명은 두 줄까지 쓴다. 라벨은 짧은 동사구나 조건(예·아니요·회차마다)으로 쓴다.
- 실제 사람 이름·계정·키·주소는 넣지 않는다.
- **시작·끝(terminal) 상자는 양 끝이 반원**이라 글이 들어갈 폭이 상자 높이만큼 줄어든다. 설명은 짧게 두 줄로 나누고(행 h 80), check.mjs 가 이 폭으로 잰다.
- **문서(인쇄)에 넣을 때 글자를 키워 찍으면**(예: 설명 11.5→13.2px, 1.15배) `node scripts/check.mjs spec.json --scale 1.15` 로 키운 글자 폭을 잰다. 경고가 남으면 열 폭(grid.colWidth)을 넓히거나 글을 줄인다.
- 판단(마름모) 옆 선 라벨이 옆 상자에 닿으면 열 간격(grid.colStep − colWidth)을 50px 이상으로 둔다.

## 기본 모양(2026-11-20 주인 확인)

생성스킬 화면의 예시(`skills/doc-generate/examples/library-relations.json` — 도서 대출 개념과 관계)가 이 스킬의 기본 결이다: 구역 띠(준비 · 실행, 둘째 구역은 옅은 파랑) · 선 끝 관계 수 · 위쪽 파란 띠 · 판단 마름모 · 중심(파랑) · 모아 보기(주황) · 바깥(점선) · 합류점과 갈림점. v1.2의 묶음 · 원형 역할 · 목록 상자 · 선 색은 구성도를 그릴 때만 더한다.

## v1.2 — 구성도 표현(공공 문서용으로 절제)

흐름도처럼 한 줄로 내려가는 그림만이 아니라, 시스템 구성도를 여러 배치로 그린다. 참고한 슬라이드 그림(역할 원 · 점선 묶음 · 색 나눈 선)의 표현을 쓰되 공공 문서에 맞게 줄인다.

- **묶음(groups)**: `{ "title": "원스톱 플랫폼 · 기관 내부망", "nodes": ["a","b"], "tone": "blue|green|amber" }` — 상자들을 감싸는 점선 테두리와 왼쪽 위 이름. 바탕은 아주 옅게.
- **상자 종류 추가**
  - `actor`: 원형 — 사람·역할(담당자, 민원인). `w`·`h`를 같게.
  - `accent`: 옅은 황토 — 그림에서 가장 중요한 한 곳만.
  - `list`: 제목 아래 작은 칸 목록 — `items: ["…","…"]`(세로) 또는 `itemsRow: true`(가로). 부서·과제 묶음처럼 구성 항목을 보일 때.
  - `plain`: 테두리 없는 글.
- **선 색(tone)**: `blue`(요청·사용) · `green`(등록·저장·수집) · `amber`(강조) 세 가지. 나머지는 회색. 점선(`dashed`)은 돌아오는 것·선택적인 것.
- **선 자리**: `"id:bottom@0.21"`처럼 변의 비율 자리에 붙인다(넓은 상자에서 두 선을 나란히). `via: "top" | "bottom"`은 그림 바깥 위·아래 길로 돌아간다.
- **세밀한 배치**: `col`에 0.5 같은 소수, 상자마다 `dx`·`dy`(px).

**절제 규칙** — 색은 세 가지까지, 강조 상자는 한 곳, 그림자·그라데이션·아이콘·이모지 없음, 글자 크기는 두 단계(제목·설명). 대신 **상세는 유지**: 상자마다 하는 일 한 줄, 목록 상자에 구성 항목, 선마다 주고받는 것.

**문서에 넣을 때** — 열은 4개 이하(넓으면 글자가 8pt 아래로 작아진다), 열 간격은 선 라벨이 들어가게 70px 이상(`colStep - colWidth`). 찍을 때 `.dg-sub 13.2px · .dg-lbl 13px · .dg-t 15px · .dg-gt 13.5px`.

예시: `skills/doc-generate/examples/civil-service-arch.json`(온라인 민원 처리 구성도).
